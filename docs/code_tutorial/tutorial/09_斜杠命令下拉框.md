# 第 09 章：斜杠命令下拉框

## 本步目标

在输入框里敲一个 `/`，输入框上方会弹出一个蓝色边框的命令下拉框，列出所有可用命令；继续打字（比如 `/m`）会实时过滤；用 ↑↓ 移动箭头选择，Enter 直接补全并执行该命令，Esc 关闭下拉框。上一章的 ↑↓ 翻历史功能保留——同一个输入框，下拉框开着时按键归下拉框，关着时归历史翻页。执行命令目前是演示性质：往聊天区打一行灰色提示（`/help` 列出全部命令，未知命令打黄色警告），真正的弹窗在下一章做。

## 新概念

- **`@on(Input.Changed)`**：Input 的内容每变一个字符，就会发出一个 `Changed` 消息。我们用装饰器 `@on(Input.Changed)` 挂一个处理器，在里头根据当前输入决定要不要弹下拉框。它和上一章的 `on_key` 的区别是：`on_key` 拿到的是「按了哪个键」，`Input.Changed` 拿到的是「内容变成了什么」，做实时过滤用后者更顺手。
- **`display: none` 控制显隐**：Textual 的每个 Widget 都有 `display` 属性，设成 `False` 就从布局里彻底消失（不占位置），设回 `True` 就回来。下拉框默认藏在 CSS 里（`display: none`），需要时改属性即可，不用 mount/remove 来回折腾。
- **键盘事件「双模式」**：上一章 `HistoryInput.on_key` 里 ↑↓ 固定翻历史。本章开头先问一句「下拉框开着吗」，开着就把 ↑↓/Enter/Esc 全部 `event.stop()` 拦截下来转交给下拉框，`return` 掉，不再走翻历史逻辑。一个组件根据界面状态切换按键的含义，这是终端 UI 里很常见的模式。
- **手动发消息 `post_message`**：Enter 被 `event.stop()` 拦截后，Input 自己就不会再发出 `Submitted` 消息了。但我们要「选中即提交」，所以自己 `self.post_message(Input.Submitted(self, self.value))` 补发一条，效果和用户直接按回车完全一样，App 里的 `on_input_submitted` 照常触发。
- **防闪烁（不重建组件）**：按 ↑↓ 只是切换选中行，如果每次都把下拉框里的组件删掉重建，画面会明显闪一下。做法是分两层：切换选中只改 CSS class 和文字（`set_class` + `Static.update`）；只有过滤后的列表内容真的变了，才 `remove_children()` + `mount_all()` 重建一次。

然后是显隐和过滤（`steps/step09_dropdown.py:221-245`）：

```python
    async def show(self) -> None:
        self.visible = True
        self.display = True       # 改 display 属性，组件立刻参与布局
        await self._render_list()

    def hide(self) -> None:
        self.visible = False
        self.display = False

    def filter(self, query: str) -> None:
        """根据输入过滤命令；不以 / 开头就藏起来。"""
        if not query.startswith("/"):
            self.hide()
            return
        query = query[1:].lower()
        self._filtered = [
            (name, desc)
            for name, desc in self._commands
            if name.startswith(query)      # 前缀匹配：/m 命中 model
        ]
        self._selected_index = 0           # 每次过滤后回到第一项
        if self._filtered:
            self.app.run_worker(self.show())   # show 是 async，用 worker 跑
        else:
            self.hide()                    # 没有匹配（如 /foobar）就藏掉
```

注意一个细节：`filter` 是普通同步方法（它会被 `@on(Input.Changed)` 的处理器调用），不能在里面直接 `await self.show()`，所以用 `self.app.run_worker()` 把它丢到后台执行——第 05 章学过的 worker 技巧在这里复用。

### 3. 渲染列表与「防闪烁」的选中切换

这是本步最核心的一个设计点（`steps/step09_dropdown.py:247-294`）：

```python
    async def _render_list(self) -> None:
        """重新渲染命令列表。列表内容没变时只更新选中态，避免销毁重建导致闪烁。"""
        names = [name for name, _ in self._filtered[:5]]      # 最多显示 5 条
        if names == self._rendered_names and self.children:
            # 列表内容没变（比如只是按了 ↑↓）：只更新选中样式，直接返回
            self._update_selection()
            return
        # 内容真变了：全删重建一次
        await self.remove_children()
        rows = [
            HorizontalGroup(
                Static(
                    f"{'→ ' if idx == self._selected_index else '  '}{name}",
                    classes="command-name",
                ),
                Static(desc, classes="command-desc"),
                classes="command-option selected" if idx == self._selected_index else "command-option",
            )
            for idx, (name, desc) in enumerate(self._filtered[:5])
        ]
        rows.append(
            Static(f"  ({len(self._filtered)}/{len(self._commands)})", classes="dropdown-count")
        )
        await self.mount_all(rows)
        self._rendered_names = names    # 记住这次渲染了什么
```

每一行是一个 `HorizontalGroup`（自动高度的横排容器，第 04 章用过）：左边 `→ 命令名`，右边灰色描述。最后一行是 `(3/5)` 这样的计数。`_rendered_names` 是关键：它记录上次实际渲染的命令名列表，下次进来先比对，没变就不碰组件树。

选中切换和移动、取值的方法：

```python
    def _update_selection(self) -> None:
        """只更新选中行的样式和箭头，不重建组件（避免闪烁）。"""
        for idx, row in enumerate(self.query(".command-option")):
            selected = idx == self._selected_index
            row.set_class(selected, "selected")          # set_class(True/False, 类名)：加/去类
            name = self._filtered[idx][0]
            arrow = "→ " if selected else "  "
            row.query_one(".command-name", Static).update(f"{arrow}{name}")

    def move_up(self) -> None:
        if self._selected_index > 0:
            self._selected_index -= 1
            self._update_selection()

    def move_down(self) -> None:
        if self._selected_index < len(self._filtered) - 1:
            self._selected_index += 1
            self._update_selection()

    def select_current(self) -> str | None:
        """返回当前选中的命令名。"""
        if 0 <= self._selected_index < len(self._filtered):
            return self._filtered[self._selected_index][0]
        return None
```

`set_class(selected, "selected")` 的意思是：`selected` 为真就加上 `selected` 类，为假就去掉它——一行代码完成互斥切换，配合 CSS 里的 `.selected .command-name` 选择器，选中行立刻变白加粗。

### 4. HistoryInput 改造：一个输入框，两套键盘行为

在上一版 `HistoryInput` 的基础上，只改 `on_key` 方法（`steps/step09_dropdown.py:306-341`），其余（`_history_previous` 等）原样保留：

```python
    async def on_key(self, event: events.Key) -> None:
        dropdown = self.app.query_one("#command-dropdown", CommandDropdown)

        # 下拉框开着：方向键和确认键先给下拉框用
        if dropdown.visible:
            if event.key == "up":
                event.stop()
                dropdown.move_up()
                return
            elif event.key == "down":
                event.stop()
                dropdown.move_down()
                return
            elif event.key == "enter":
                event.stop()
                selected = dropdown.select_current()
                if selected is not None:
                    self.value = f"/{selected}"   # 补全输入框内容
                    dropdown.hide()
                    # 选中即提交：手动发 Submitted 消息
                    self.post_message(Input.Submitted(self, self.value))
                return
            elif event.key == "escape":
                event.stop()
                dropdown.hide()
                return

        # 下拉框关着：↑↓ 翻历史（上一章的逻辑，原封不动）
        if event.key == "up":
            event.stop()
            self._history_previous()
        elif event.key == "down":
            event.stop()
            self._history_next()
        else:
            self._history_pos = None
```

要点有三个：

- 每次按键都先 `query_one` 拿到下拉框问 `visible`，这是「双模式」的开关。
- 每个分支都 `event.stop()` + `return`：拦下来的键绝不能再落回翻历史逻辑，也不能传给别的组件（比如滚动区把 ↑↓ 当滚屏）。
- Enter 分支里 `self.post_message(Input.Submitted(self, self.value))`：因为我们 `event.stop()` 掉了原始的 Enter，Input 不会自己提交，必须手动补发。这样 App 的 `on_input_submitted` 完全不用改。

### 5. ChatApp 接线：放下拉框、接 Changed 事件、分流命令

在上一版 `ChatApp` 的基础上做三处改动。

第一处，`compose()` 里在输入行上方加下拉框（`steps/step09_dropdown.py:436-444`）。注意它和输入行放在同一个 `#input-area` 容器里，先声明的在上面：

```python

                yield HistoryInput(placeholder="", id="user-input")
```

`#input-area` 是 `dock: bottom` 的，下拉框长在它内部，所以弹出时是把输入行往下顶，而不是浮在上面——效果上和 Claude Code 的补全框一致。

第二处，新增 `@on(Input.Changed)` 处理器（`steps/step09_dropdown.py:450-456`）：

```python
    @on(Input.Changed)
    def on_input_changed(self, event: Input.Changed) -> None:
        """输入变化时，根据内容决定是否显示命令下拉。"""
        if event.input.id != "user-input":
            return
        dropdown = self.query_one("#command-dropdown", CommandDropdown)
        dropdown.filter(event.value)
```

`event.input` 是发出消息的 Input 组件，`event.value` 是变化后的完整内容。每敲一个字符这里都会跑一次 `filter`，实现实时过滤。注意连「程序赋值 `self.value = f"/{selected}"`」也会触发 `Changed`——但因为此时下拉框已被 hide，filter 会按新值重新判断，以 `/model` 开头会再次弹出，随后提交清空输入框又触发一次 `Changed`（值为空，不以 `/` 开头）把它关掉，状态自然收敛，不用特判。

第三处，`on_input_submitted` 里把 `/` 开头的输入分流给 `handle_command`（`steps/step09_dropdown.py:458-471`）：

```python
    async def on_input_submitted(self, event: Input.Submitted) -> None:
        user_text = event.value.strip()

        input_widget = self.query_one("#user-input", HistoryInput)
        input_widget.value = ""
        input_widget.push_history(user_text)

        if not user_text:
            return

        # 以 / 开头 → 走命令分发，不走聊天
        if user_text.startswith("/"):
            await self.handle_command(user_text[1:])
            return

        scroll = self.query_one("#chat-scroll", VerticalScroll)
        await scroll.mount(UserMessage(user_text))
        # ... 后面和上一章一样：挂 AssistantMessage、anchor、起流式 worker
```

和上一版相比，变化是：清空输入框、记历史这两步挪到了空值判断**之前**（空提交也要重置历史游标），然后多了 `/` 分流。

### 6. 命令分发 handle_command

新增一个方法（`steps/step09_dropdown.py:482-502`），本步只是演示——往聊天区打一行提示：

```python
    async def handle_command(self, command: str) -> None:
        """处理斜杠命令（本步只是演示：往聊天区打一行提示）。"""
        scroll = self.query_one("#chat-scroll", VerticalScroll)
        known = {name for name, _ in COMMANDS}
        if command == "help":
            names = " ".join(f"/{name}" for name, _ in COMMANDS) + " /help"
            await scroll.mount(
                Static(Text(f"  Available commands: {names}", style="#7a8391"), classes="tip-sub")
            )
        elif command in known:
            await scroll.mount(
                Static(
                    Text(f"  命令 /{command} 已选中（弹窗效果见第 10 步）", style="#7a8391"),
                    classes="tip-sub",
                )
            )
        else:
            await scroll.mount(
                Static(Text(f"  Unknown command: /{command}", style="#e5c07b"), classes="warning")
            )
        scroll.anchor()
```

三种情况：`/help` 列出全部命令；已知命令打灰色提示（下一章把 `/model` 变成真弹窗）；未知命令打黄色警告。最后记得 `scroll.anchor()` 吸底。App 的 CSS 里也要给这两个新类补上样式（`.tip-sub` 和 `.warning`，都是 `width: 1fr; height: auto; margin: 0 1 0 1;`），见完整代码。

        self._filtered: list[tuple[str, str]] = self._commands
        self._selected_index = 0
        # 上一次实际渲染的命令名列表，用来判断「列表内容有没有变」
        self._rendered_names: list[str] = []
        self.visible = False

    def compose(self) -> ComposeResult:
        return []

    async def show(self) -> None:
        self.visible = True
        self.display = True
        await self._render_list()

    def hide(self) -> None:
        self.visible = False
        self.display = False

    def filter(self, query: str) -> None:
        """根据输入过滤命令；不以 / 开头就藏起来。"""
        if not query.startswith("/"):
            self.hide()
            return
        query = query[1:].lower()
        self._filtered = [
            (name, desc)
            for name, desc in self._commands
            if name.startswith(query)
        ]
        self._selected_index = 0
        if self._filtered:
            self.app.run_worker(self.show())
        else:
            self.hide()

    async def _render_list(self) -> None:
        """重新渲染命令列表。列表内容没变时只更新选中态，避免销毁重建导致闪烁。"""
        names = [name for name, _ in self._filtered[:5]]
        if names == self._rendered_names and self.children:
            self._update_selection()
            return
        await self.remove_children()
        rows = [
            HorizontalGroup(
                Static(
                    f"{'→ ' if idx == self._selected_index else '  '}{name}",
                    classes="command-name",
                ),
                Static(desc, classes="command-desc"),
                classes="command-option selected" if idx == self._selected_index else "command-option",
            )
            for idx, (name, desc) in enumerate(self._filtered[:5])
        ]
        rows.append(
            Static(f"  ({len(self._filtered)}/{len(self._commands)})", classes="dropdown-count")
        )
        await self.mount_all(rows)
        self._rendered_names = names

    def _update_selection(self) -> None:
        """只更新选中行的样式和箭头，不重建组件（避免闪烁）。"""
        for idx, row in enumerate(self.query(".command-option")):
            selected = idx == self._selected_index
            row.set_class(selected, "selected")
            name = self._filtered[idx][0]
            arrow = "→ " if selected else "  "
            row.query_one(".command-name", Static).update(f"{arrow}{name}")

    def move_up(self) -> None:
        if self._selected_index > 0:
            self._selected_index -= 1
            self._update_selection()

    def move_down(self) -> None:
        if self._selected_index < len(self._filtered) - 1:
            self._selected_index += 1
            self._update_selection()

    def select_current(self) -> str | None:
        """返回当前选中的命令名。"""
        if 0 <= self._selected_index < len(self._filtered):
            return self._filtered[self._selected_index][0]
        return None


class HistoryInput(Input):
    """带历史记忆的输入框；下拉框可见时，↑↓/Enter/Esc 优先给下拉框。"""

    def __init__(self, *args, **kwargs) -> None:
        super().__init__(*args, **kwargs)
        self._history: list[str] = []
        self._history_pos: int | None = None
        self._draft: str = ""

    async def on_key(self, event: events.Key) -> None:
        dropdown = self.app.query_one("#command-dropdown", CommandDropdown)

        # 下拉框开着：方向键和确认键先给下拉框用
        if dropdown.visible:
            if event.key == "up":
                event.stop()
                dropdown.move_up()
                return
            elif event.key == "down":
                event.stop()
                dropdown.move_down()
                return
            elif event.key == "enter":
                event.stop()
                selected = dropdown.select_current()
                if selected is not None:
                    self.value = f"/{selected}"
                    dropdown.hide()
                    # 选中即提交
                    self.post_message(Input.Submitted(self, self.value))
                return
            elif event.key == "escape":
                event.stop()
                dropdown.hide()
                return

        # 下拉框关着：↑↓ 翻历史
        if event.key == "up":
            event.stop()
            self._history_previous()
        elif event.key == "down":
            event.stop()
            self._history_next()
        else:
            self._history_pos = None

    def _history_previous(self) -> None:
        if not self._history:
            return
        if self._history_pos is None:
            self._draft = self.value
            self._history_pos = len(self._history) - 1
        elif self._history_pos > 0:
            self._history_pos -= 1
        self.value = self._history[self._history_pos]

    def _history_next(self) -> None:
        if self._history_pos is None:
            return
        self._history_pos += 1
        if self._history_pos >= len(self._history):
            self._history_pos = None
            self.value = self._draft
        else:
            self.value = self._history[self._history_pos]

    def push_history(self, text: str) -> None:
        if text:
            self._history.append(text)
        self._history_pos = None
        self._draft = ""



class ChatScroll(VerticalScroll):
    """聊天滚动区：修复 anchor() 的一个小 bug。

    anchor() 让滚动区一直吸底；但 Textual 的合成器在「内容不足一屏」时
    会把 scroll_y 直接设成负数（set_reactive 绕过了 0 下限的校验），表现为：
    第一次发消息后，上面的内容整体往下挪、顶部空出一片。
    这里把负的滚动值挡回去即可。
    """

    def set_reactive(self, reactive, value) -> None:
        if (
            isinstance(value, (int, float))
            and value < 0
            and (reactive is Widget.scroll_y or reactive is Widget.scroll_target_y)
        ):
            value = 0
        super().set_reactive(reactive, value)


class ChatApp(App):
    CSS = """
    Screen {
        layout: vertical;
    }
    #chat-scroll {
        width: 1fr;
        height: 1fr;
        padding: 0;
    }
    #input-area {
        dock: bottom;
        width: 1fr;
        height: auto;
    }
    #input-row {
        width: 1fr;
        height: 3;
        border: round #3a3f4a;
        padding: 0 1;
        margin: 1 1 0 1;
    }
    #prompt {
        width: auto;
        height: auto;
        color: #c8cdd5;
        padding-right: 1;
    }
    #user-input {
        width: 1fr;
        height: auto;
        border: none;
        padding: 0;
    }
    .tip-sub {
        width: 1fr;
        height: auto;
        margin: 0 1 0 1;
    }
    .warning {
        width: 1fr;
        height: auto;
        margin: 0 1 0 1;
    }
    """

    def compose(self) -> ComposeResult:
        with ChatScroll(id="chat-scroll"):
            yield WelcomeBox()
        with Vertical(id="input-area"):
            # 下拉框放在输入框上方（同一个容器里，先声明的在上面）
            yield CommandDropdown(id="command-dropdown")
            with Horizontal(id="input-row"):
                yield Static(">", id="prompt")
                yield HistoryInput(placeholder="", id="user-input")

    def on_mount(self) -> None:
        """启动后自动聚焦输入框。"""
        self.query_one("#user-input", Input).focus()

    @on(Input.Changed)
    def on_input_changed(self, event: Input.Changed) -> None:
        """输入变化时，根据内容决定是否显示命令下拉。"""
        if event.input.id != "user-input":
            return
        dropdown = self.query_one("#command-dropdown", CommandDropdown)
        dropdown.filter(event.value)

    async def on_input_submitted(self, event: Input.Submitted) -> None:
        user_text = event.value.strip()

        input_widget = self.query_one("#user-input", HistoryInput)
        input_widget.value = ""
        input_widget.push_history(user_text)

        if not user_text:
            return

        # 以 / 开头 → 走命令分发，不走聊天
        if user_text.startswith("/"):
            await self.handle_command(user_text[1:])
            return

        scroll = self.query_one("#chat-scroll", VerticalScroll)
        await scroll.mount(UserMessage(user_text))
        message = AssistantMessage()
        await scroll.mount(message)

        scroll.anchor()

        self.run_worker(self.stream_response(message))

    async def handle_command(self, command: str) -> None:
        """处理斜杠命令（本步只是演示：往聊天区打一行提示）。"""
        scroll = self.query_one("#chat-scroll", VerticalScroll)
        known = {name for name, _ in COMMANDS}
        if command == "help":
            names = " ".join(f"/{name}" for name, _ in COMMANDS) + " /help"
            await scroll.mount(
                Static(Text(f"  Available commands: {names}", style="#7a8391"), classes="tip-sub")
            )
        elif command in known:
            await scroll.mount(
                Static(
                    Text(f"  命令 /{command} 已选中（弹窗效果见第 10 步）", style="#7a8391"),
                    classes="tip-sub",
                )
            )
        else:
            await scroll.mount(
                Static(Text(f"  Unknown command: /{command}", style="#e5c07b"), classes="warning")
            )
        scroll.anchor()

    async def stream_response(self, message: AssistantMessage) -> None:
        """先逐字写出思考过程，再流式输出回答。"""
        thinking_content = message.query_one("#thinking-content", Static)
        thinking_row = message.query_one(".thinking-row")
        buffer = ""
        for char in THINKING:
            if not buffer:
                thinking_row.remove_class("stream-pending")
            buffer += char
            thinking_content.update(buffer)
            await asyncio.sleep(0.02)

        md = message.query_one("#answer-md", Markdown)
        answer_row = message.query_one(".answer-row")
        stream = Markdown.get_stream(md)
        try:
            for i in range(0, len(ANSWER), 8):
                if i == 0:
                    answer_row.remove_class("stream-pending")
                await stream.write(ANSWER[i : i + 8])
                await asyncio.sleep(0.05)
        finally:
            await stream.stop()


if __name__ == "__main__":

    app.run()

## 常见问题

- **Enter 选中后没有提交？** 检查 Enter 分支里有没有 `self.post_message(Input.Submitted(self, self.value))`。`event.stop()` 拦截了原始按键后，Input 不会再自己发 `Submitted`，少这一行就是「输入框补全了但没反应」。
- **`filter` 里为什么不能直接 `await self.show()`？** `filter` 是被 `@on(Input.Changed)` 处理器同步调用的普通方法，不是 async。所以代码里用 `self.app.run_worker(self.show())` 把异步的 `show()` 丢给后台执行，和第 05 章流式输出用 worker 是同一个套路。
- **手动运行或截图时界面变成灰色？** 如果环境变量 `NO_COLOR=1`，Textual 会进入灰度模式。运行或截图前用 `env -u NO_COLOR python steps/step09_dropdown.py`（PowerShell 先 `$env:NO_COLOR=""` 再运行）。

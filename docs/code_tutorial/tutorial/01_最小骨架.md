## 本步目标

做出一个最小但能跑的聊天界面：上面是一块可滚动的聊天记录区，下面是一个钉在底部的输入框；输入文字按回车，输入框清空，聊天区多出一条「你： xxx」和一条固定的「AI: 收到！」，并自动滚到底部。这是后面 11 步共同的地基。

## 新概念

- **App**：一个 Textual 程序就是一个继承 `App` 的类。它负责创建窗口、分发键盘鼠标事件、管理界面上的所有组件。`app.run()` 启动事件循环，程序开始等待你的操作。
- **Widget（组件）**：界面上的一切都是组件——输入框、一段文字、一个容器。本步用到三个：`VerticalScroll`（可滚动容器，放聊天记录）、`Input`（单行输入框）、`Static`（显示一段静态文本）。
- **compose()**：`App` 一启动就会调用这个方法，你在里面用 `yield` 把初始组件交出去，Textual 负责把它们画到屏幕上。它决定了「这个界面一打开长什么样」。
- **CSS**：Textual 借用了网页 CSS 的语法来控制布局，但写法更简单。`#user-input` 按组件的 `id` 选中某个组件，`dock: bottom` 把它钉在屏幕底部，`height: 1fr` 表示「占满剩余空间」。不需要懂网页 CSS 也能看懂。
- **消息与事件**：用户做了什么（按键、回车、点击），Textual 会发一个「消息」给相关组件。你在 App 里定义一个叫 `on_input_submitted` 的方法，Textual 看到 `Input` 发出 `Submitted` 消息时就会自动调用它。方法名的规则是 `on_组件名_消息名`。
- **query_one()**：按选择器在界面上找一个组件，比如 `self.query_one("#user-input", Input)` 就是「找到 id 为 user-input 的那个 Input」。
- **mount()**：往已经显示的界面上动态挂一个新组件。聊天记录就是这样一条一条加进去的。

## 动手实现

### 1. 先搭 App 骨架和样式

新建 `steps/step01_basic.py`，先写类定义和 CSS：

```python
from textual.app import App, ComposeResult
from textual.containers import VerticalScroll
from textual.widgets import Input, Static


class ChatApp(App):
    CSS = """
    Screen {
        layout: vertical;
    }
    #chat-scroll {
        width: 1fr;
        height: 1fr;
        padding: 1 2;
    }
    #user-input {
        dock: bottom;
        height: auto;
        padding: 1 2;
    }
    """
```

`CSS` 是 App 级别的样式表，整个界面生效。逐条看：

- `Screen { layout: vertical; }`：整个屏幕自上而下竖排组件（这是默认值，写出来是为了直观）。
- `#chat-scroll`：聊天记录区。`width: 1fr; height: 1fr` 让它占满除输入框外的所有空间；`padding: 1 2` 是上下 1 格、左右 2 格的内边距，文字不贴着屏幕边缘。
- `#user-input`：`dock: bottom` 是这一步的关键——把输入框钉在底部，聊天区再高也不会把它顶出屏幕。`height: auto` 让它按内容（一行输入框加内边距）决定高度。

### 2. 用 compose() 摆出初始界面

```python
    def compose(self) -> ComposeResult:
        # 可滚动的聊天记录区（现在是空的，消息以后动态加进去）
        with VerticalScroll(id="chat-scroll"):
            pass
        # 底部输入框
        yield Input(placeholder="输入问题，按 Enter 发送", id="user-input")
```

`compose` 是个生成器。这里用了一个简写：`with VerticalScroll(...)` 块里 `yield` 的组件会成为它的子组件——现在块里是 `pass`，所以它是个空容器；块结束后 `yield Input(...)` 把输入框作为屏幕的第二个孩子交出去。`placeholder` 是输入框为空时显示的灰色提示文字。

### 3. 启动后聚焦输入框

```python
    def on_mount(self) -> None:
        """启动后自动聚焦输入框，这样一打开就能直接打字。"""
        self.query_one("#user-input", Input).focus()
```

`on_mount` 在组件挂载完成后被调用一次。这里必须显式 `focus()`：不聚焦的话，键盘按键会被可滚动的聊天区抢走，你在输入框里打字会毫无反应。这是新手最容易踩的坑，后面每一步都保留了这一行。

### 4. 接住回车事件，把消息挂进聊天区

```python
    async def on_input_submitted(self, event: Input.Submitted) -> None:
        """用户按下回车时触发。"""
        user_text = event.value.strip()
        if not user_text:
            return

        # 清空输入框
        self.query_one("#user-input", Input).value = ""

        # 把用户消息和一条固定的 AI 回复挂到滚动区
        scroll = self.query_one("#chat-scroll", VerticalScroll)
        await scroll.mount(Static(f"你: {user_text}"))
        await scroll.mount(Static("AI: 收到！"))

        # 滚动到底部，让新消息可见
        scroll.scroll_end(animate=False)
```

按顺序做的事：

1. `event.value` 是输入框里的文字，`strip()` 去掉首尾空白；空消息直接忽略。
2. 把输入框的 `value` 设为空字符串，输入框清空。
3. `await scroll.mount(...)` 往滚动区里挂两个 `Static`：一条显示用户刚说的话，一条是写死的假 AI 回复（真的 AI 到第 05 步才来）。
4. `scroll_end(animate=False)` 立刻滚到底部，保证新消息看得见。`animate=False` 是不带滚动动画，瞬间到位。

### 5. 入口

```python
if __name__ == "__main__":
    app = ChatApp()
    app.run()
```

`app.run()` 启动应用，终端被 Textual 接管，直到你按 `Ctrl+C` 退出。

## 完整代码

下面是 `steps/step01_basic.py` 的完整源码，和仓库里的文件逐字一致，可以直接 `python steps/step01_basic.py` 运行对照：

```python
"""第 1 步：最小可运行的聊天界面。

学到什么：
- App 和 compose()：界面由一个个组件（Widget）组成。
- VerticalScroll：可滚动的容器，用来放聊天记录。
- Input：底部输入框。
- on_input_submitted：按下回车触发的事件。
- mount()：把新消息组件挂到滚动区里。
- query_one()：按 id 找到某个组件。
- on_mount()：启动后做一件事——把焦点放到输入框上。
  （不聚焦的话，按键会被可滚动的聊天区抢走，打字没反应。）
"""

from textual.app import App, ComposeResult
from textual.containers import VerticalScroll
from textual.widgets import Input, Static


class ChatApp(App):
    CSS = """
    Screen {
        layout: vertical;
    }
    #chat-scroll {
        width: 1fr;
        height: 1fr;
        padding: 1 2;
    }
    #user-input {
        dock: bottom;
        height: auto;
        padding: 1 2;
    }
    """

    def compose(self) -> ComposeResult:
        # 可滚动的聊天记录区（现在是空的，消息以后动态加进去）
        with VerticalScroll(id="chat-scroll"):
            pass
        # 底部输入框
        yield Input(placeholder="输入问题，按 Enter 发送", id="user-input")

    def on_mount(self) -> None:
        """启动后自动聚焦输入框，这样一打开就能直接打字。"""
        self.query_one("#user-input", Input).focus()

    async def on_input_submitted(self, event: Input.Submitted) -> None:
        """用户按下回车时触发。"""
        user_text = event.value.strip()
        if not user_text:
            return

        # 清空输入框
        self.query_one("#user-input", Input).value = ""

        # 把用户消息和一条固定的 AI 回复挂到滚动区
        scroll = self.query_one("#chat-scroll", VerticalScroll)
        await scroll.mount(Static(f"你: {user_text}"))
        await scroll.mount(Static("AI: 收到！"))

        # 滚动到底部，让新消息可见
        scroll.scroll_end(animate=False)


if __name__ == "__main__":
    app = ChatApp()
    app.run()
```

```bash
python steps/step01_basic.py
```

应该看到：一个几乎空白的屏幕，底部有一个输入框，显示灰色提示「输入问题，按 Enter 发送」，光标已经在输入框里闪烁。

动手验证：

- 输入 `你好`，按回车。输入框清空，上方出现「你： 你好」和「AI: 收到！」。
- 直接按回车（不输入内容），什么都不会发生——空消息被忽略了。
- 连发十几条消息，内容超出屏幕后滚动区可以滚动；每发一条新消息都会滚回底部。
- 试试不按回车先用鼠标点聊天区，再打字——焦点还在输入框上，因为我们没有给聊天区可聚焦的内容；但如果你删掉 `on_mount` 里的 `focus()`，启动后直接打字就没反应了，可以亲自体会一下这行的作用。

这几条都符合预期，就说明本步的三个关键点——回车发消息、空消息忽略、自动滚到底——都成立了。

## 常见问题

- **打字没反应？** 九成是忘了 `on_mount` 里的 `input.focus()`。可滚动的聊天区默认会抢键盘焦点，按键全被它吃掉。这也是本教程从第 01 步起每个 App 都带这一行的原因。
- **`dock: bottom` 和 `height: 1fr` 分别管什么？** `dock` 决定输入框「钉在哪」，`1fr` 决定聊天区「占满剩下的空间」。两个配合才有「输入框固定底部、聊天区自动伸缩」的效果。把 `dock: bottom` 删掉，输入框会跑到聊天区下面被挤出屏幕。
- **为什么 `mount()` 前面要加 `await`？** 挂载组件是异步操作——Textual 要在后台安排布局计算和重绘。`on_input_submitted` 因此也必须是 `async def`。忘了 `await` 不会报错，但组件出现的时机就不可控了。
